# Trigonometric Identity Tester 📐

A lightweight Python script designed to test the fundamental trigonometric identity:
**cos²(x) + sin²(x) = 1**

---

## 🚀 Overview

This program prompts you to input an integer value for $x$, calculates the sum of the squared cosine and sine of that value using Python's built-in `math` module, and prints the result. Because of floating-point precision, it's a fun way to observe how programming languages handle mathematical identities!

---

## 🛠️ Prerequisites

* **Python 3.x** installed on your machine. No external libraries or third-party packages are required.

---

## 💻 How to Run

1. Clone or download this repository.
2. Open your terminal or command prompt in the directory containing the script.
3. Run the script using Python:
```bash
python script.py

```


4. Enter any integer when prompted.

---

## 📊 Example Usage

```text
Enter test value: 45
The result of the trigonometry rule with x being 45 is 1.0

```
